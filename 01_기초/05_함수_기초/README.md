# 05. 함수 기초

> 단계: 기초 | 선수: 04_제어문

## 학습 목표
- 함수 선언문과 함수 표현식, 화살표 함수를 작성할 수 있다.
- 매개변수의 기본값, 나머지 매개변수(rest) 를 사용할 수 있다.
- 인자(argument) 와 매개변수(parameter) 의 차이를 설명할 수 있다.
- 함수 스코프와 블록 스코프를 구분한다.
- 순수 함수(pure function) 의 개념을 이해한다.

## 1. 함수 선언 vs 표현식 vs 화살표
함수 선언문은 호이스팅되어 위에서도 호출할 수 있습니다. 표현식과 화살표 함수는 변수에 할당된 이후부터 사용 가능합니다. 화살표 함수는 짧고 자체 `this` 를 가지지 않아 콜백에 적합합니다.

```js
function add(a, b) { return a + b; }     // 선언문
const sub = function (a, b) { return a - b; }; // 표현식
const mul = (a, b) => a * b;             // 화살표
```

## 2. 매개변수와 인자
매개변수에 기본값을 지정할 수 있고, `...rest` 로 가변 인자를 받을 수 있습니다.

```js
function greet(name = "친구") {
  return `안녕, ${name}!`;
}
function sum(...nums) {
  return nums.reduce((a, b) => a + b, 0);
}
```

## 3. return 과 부수 효과
함수는 명시적으로 `return` 한 값을 돌려주며, 없으면 `undefined` 입니다. 입력이 같으면 항상 같은 결과를 반환하고 외부 상태를 바꾸지 않는 함수를 "순수 함수" 라 부릅니다.

```js
// 순수
const square = (x) => x * x;

// 비순수: 외부 상태 변경
let counter = 0;
const tick = () => { counter += 1; };
```

## 4. 스코프
변수는 선언된 블록 안에서만 보입니다. `let`/`const` 는 블록 스코프, `var` 는 함수 스코프입니다. 함수 안에서 바깥 변수를 참조하는 것을 클로저(다음 단계에서 자세히) 라고 합니다.

```js
function outer() {
  const a = 1;
  if (true) {
    const b = 2;
    console.log(a, b); // 1 2
  }
  // console.log(b); // ReferenceError
}
```

## ⚠️ 자주 하는 실수
1. 화살표 함수에서 `this` 가 외부의 `this` 라는 사실을 잊고 메서드로 정의해 버그를 만드는 경우.
2. 매개변수 기본값이 `undefined` 일 때만 적용된다는 사실을 잊고 `null` 을 넘기는 경우.
3. `return` 을 빠뜨려 `undefined` 가 반환되는 줄 모르는 경우.
4. 화살표 함수에서 객체 리터럴을 바로 반환할 때 괄호를 빠뜨림 (`() => ({ a: 1 })`).
5. 함수가 외부 변수를 몰래 변경해 추적이 어려운 버그를 만드는 경우.

## ❓ 자주 묻는 질문 (FAQ)
**Q1. 선언문과 표현식 중 무엇을 쓸까요?** A. 모듈 최상단에 정의되는 유틸은 선언문이 가독성이 좋고, 콜백/지역 함수는 화살표가 간결합니다.

**Q2. 인자가 너무 많아질 땐?** A. 객체로 묶어 받으세요. `function create({ name, age, role }) { ... }` 처럼 구조 분해를 활용합니다.

**Q3. 함수도 값인가요?** A. 네. 변수에 할당하고, 다른 함수에 인자로 넘기고, 결과로 반환할 수 있습니다. 이를 "일급 함수" 라고 부릅니다.
