# 11. 배열 고차함수 — 과제

## homework_01.js
학생 배열의 평균 점수를 reduce 로 구하세요.
```
[ { name:"A", score:80 }, { name:"B", score:90 }, { name:"C", score:70 } ]
```

## homework_02.js
상품 배열에서 카테고리별 총액을 객체로 반환하세요.
```
[ { name:"사과", category:"과일", price:1000 },
  { name:"바나나", category:"과일", price:1500 },
  { name:"우유", category:"유제품", price:2500 } ]
→ { 과일: 2500, 유제품: 2500 }
```
