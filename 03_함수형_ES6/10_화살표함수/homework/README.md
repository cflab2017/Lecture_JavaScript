# 10. 화살표 함수 — 과제

## homework_01.js
아래 함수들을 화살표 함수로 바꾸세요.
```js
function add(a, b) { return a + b; }
function isEven(n) { return n % 2 === 0; }
function shout(msg) { return msg.toUpperCase() + "!"; }
```

## homework_02.js
`makePoint(x, y)` 를 화살표 함수로 작성해 `{ x, y, distance }` 객체를 반환하세요.
`distance` 는 원점에서의 거리.
